O que é o Github?

É Basicamente uma aplicação para guardar código na nuvem

Mas é muito mais do que isso

O GitHub apoia todo o ciclo de desenvolvimento

  • Planejamento: Issues e Projects
  • Criação: repositórios e histórico
  • Revisão: pull requests
  • Teste: automação com Actions
  • Deploy: releases, Pages e Packages
  • Operação: dependências e segurança

Git ≠ GitHub

Git

  • Sistema de controle de versão
  • Código aberto
  • Roda na sua máquina

GitHub

  • Plataforma construída sobre o Git
  • Hospeda repositórios e adiciona colaboração, automação e mais

Github também é uma rede social

Onde voce pode compartilhar seu código com estranhos na internet
